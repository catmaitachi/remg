## 🎯 O que é
Revisar os diagramas do [03-modelagem](../spec/03-modelagem.md) para que **batam com o código final**, e exportar versões bonitas para o relatório e os slides.

## 🤔 Por que importa
O PDF diz que **o UML é avaliado**. Diagrama que não bate com o código perde ponto.

## 🧭 Como começar
1. Comparar cada classe do diagrama com `core/`.
2. Diagramas: casos de uso, classes, sequência (falha e rota alternativa), estados e pacotes (hexágono).
3. Usar a skill `diagram-design` ou exportar o Mermaid para SVG/PNG.
